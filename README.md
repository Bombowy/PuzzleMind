# PuzzleMind

PuzzleMind to projekt w Pythonie znajdujący się na wczesnym etapie rozwoju.

## Wymagania

- Python 3.10 lub nowszy

## Uruchomienie

```bash
python main.py
```

## Struktura projektu

- `main.py` – punkt wejścia aplikacji.

## Rozwój

Kod projektu będzie rozwijany wraz z kolejnymi funkcjami aplikacji.
